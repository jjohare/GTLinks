# GTLinks asset build scripts

Every GLB under `web/public/assets/` is generated by Blender Python from these scripts and
`assets/cars.json` (dimensions and paint colours are read from it, never retyped).

| file | role |
|---|---|
| `gtl.py` | shared helpers: material factory, `MB` mesh builder (game frame in, Blender frame out), plain GLB export |
| `cars.py` | the four SUVs: station tables (silhouette), details, wheels, detachable parts |
| `props.py`, `lodge.py` | stein, table, trees, spectator, flag, tee marker, golf cart, ramp, sign, rock, drone, lodge + chairlift |
| `build.py` | entry script (runs inside Blender) |
| `render.py` | preview renders; re-imports the exported GLBs so the picture is what the game loads |
| `validate.py` | plain Python GLB checker, no Blender needed; writes `docs/evidence/assets/validation.json` |
| `run.sh` | stages sources to the GPU sidecar, runs the job, copies results back |

## Rebuild

Blender runs in the GPU sidecar, so everything goes through `blender-job.js` (wrapped by `run.sh`):

```
assets/src/run.sh build all                 # 4 cars + 13 props  -> web/public/assets/{cars,props}/
assets/src/run.sh build escapade_2009       # or one name / comma list / cars / props
assets/src/run.sh render cars,lodge,propsheet,propsheet2,steincloseup   # -> docs/evidence/assets/*.png
python3 assets/src/validate.py              # -> docs/evidence/assets/validation.json (exit 1 on failure)
```

`run.sh` copies `assets/src` and `cars.json` into `/home/devuser/gui-tools/gtl` (the sidecar sees it as
`/home/devuser/exchange/gtl`), submits `build.py` with `--src --cars --out --what`, waits, and copies the GLBs back.

## Conventions

* Geometry is authored in the game frame (+X car left, +Y up, +Z forward) and mapped once to Blender
  `(x, y, z) -> (x, -z, y)`; the glTF exporter then yields +Z forward, +Y up, +X left.
* Exports are plain GLB: no Draco, no meshopt, no images (so no KTX/WebP), no animations, factor-only PBR materials.
* No real marque names, badges or logos anywhere; the designs are original generic SUVs.
* Extra car nodes beyond the contract (all children of `car`): `trim`, `chrome`, `grille`, `taillights`.
